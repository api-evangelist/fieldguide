# Fieldguide

> Fieldguide is an AI-native platform for audit and advisory firms. Its REST API (https://api.fieldguide.io) exposes companies, engagements, requests, sheets, files, comments, milestones, controls, users, insights exports, jobs, and webhook subscriptions. Authentication is bearer JWT / API tokens scoped by resource permission (`<resource>:read` / `<resource>:write`).
